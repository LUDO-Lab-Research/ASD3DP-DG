# Downloads

The [ASD3DP-DG Zenodo record](https://doi.org/10.5281/zenodo.23068430) distributes three 7-Zip archive groups: `all` (7 numbered parts), `clipped` (6 parts), and `annotations` (1 part). Download every part of a group into the same directory, then extract its `.001` file. Extract the groups into one release directory to reconstruct the complete layout. After extraction, verify the files against the top-level `SHA256SUMS`.

The `all/audio-archives` folder holds 78 independently extractable full-session audio archives. The `clipped/audio-archives` folder holds 78 independently extractable selected-clip archives. The `annotations` folder contains 185 CSV tables, and `all/evidence` contains their supporting records. These are session archives rather than parts of one split archive; extract only the sessions you need. Do not combine files from different datasets.

The [GitHub repository](https://github.com/LUDO-Lab-Research/ASD3DP-DG) contains the public guide and research code references.
