Downloads

The ASD3DP-DG dataset on Google Drive contains three groups: all, annotations, and clipped. Check downloaded files against the top-level SHA256SUMS before use.

The all/audio-archives folder holds 78 independently extractable full-session audio archives. The clipped/audio-archives folder holds 78 independently extractable selected-clip archives. The annotations folder contains 185 CSV tables, and all/evidence contains their supporting records. These are session archives rather than parts of one split archive; extract only the sessions you need. Do not combine files from different datasets.

The GitHub repository contains the public guide and research code references.
