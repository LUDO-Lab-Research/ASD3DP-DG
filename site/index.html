ASD3DP-DG Dataset Guide

ASD3DP-DG extends ASD3DP with recordings from three independently assembled 3D printers, labeled A, B, and C. It supports anomalous sound detection under differences between printer builds. The dataset contains four microphone channels per recording session.

Collection measure Count
Printer domains 3
Recorded sessions 78
Continuous audio 40.05 hours
Selected 10-second intervals 11,861
Mono channel views of selected intervals 47,444

These counts describe the selected collection before any benchmark subsampling. The dataset on Google Drive contains the audio, annotations, evidence, and checksums; see Downloads.
